# MDPorto WordPress Theme

A modern, elegant WordPress block theme designed for portfolio websites, with a focus on showcasing creative work and professional skills.

## Description

MDPorto is a custom WordPress block theme built for the Full Site Editing experience. It provides a clean, professional design perfect for developers, designers, photographers, and other creative professionals who want to showcase their portfolio in a modern and elegant way.

The theme features a responsive design, custom animations, and specialized sections for showcasing portfolio items, skills, services, testimonials, and contact information.

## Features

- **Full Site Editing Support**: Built for the WordPress block editor with full site editing capabilities
- **Custom Portfolio System**: Integrated custom post type for portfolio items with categories and tags
- **Modern Mobile Menu**: Responsive navigation with animated submenus and touch-friendly design
- **Pre-designed Sections**: Ready-to-use sections for about, services, portfolio, testimonials, and contact
- **Custom Block Patterns**: Reusable design patterns to quickly build pages
- **Elegant Typography**: Carefully selected fonts and typography settings
- **Animation Effects**: Subtle animations to enhance user experience
- **SVG Support**: Built-in support for SVG uploads and display
- **Performance Optimized**: Lightweight and fast-loading design
- **Customization Options**: Easily customize colors, fonts, and layouts

## Templates

MDPorto includes the following templates:

- **Front Page**: Custom homepage design with hero section
- **Portfolio Archive**: Grid layout for portfolio items with filtering options
- **Single Portfolio**: Detailed view for individual portfolio items
- **Blog Archive**: Modern card-based layout for blog posts
- **Single Post**: Clean and elegant single post layout
- **Page Templates**: Standard and no-title page templates
- **404 Page**: Custom not found page
- **Search Results**: Styled search results page

## Sections

The theme includes pre-designed sections that can be added to any page:

- **Hero Developer**: Showcase your name, title, and skills
- **About**: Share your background and expertise
- **Services**: Display your professional services
- **Portfolio**: Showcase your work in a grid layout
- **Testimonials**: Display client testimonials
- **Contact**: Contact form and information
- **Fastwork CTA**: Call-to-action section

## Installation

### Manual Installation

1. Download the `mdporto.zip` file
2. Go to your WordPress admin dashboard
3. Navigate to **Appearance** > **Themes** > **Add New**
4. Click **Upload Theme**
5. Choose the downloaded zip file and click **Install Now**
6. After installation, click **Activate**

### Developer Installation

1. Open your terminal
2. Navigate to your WordPress themes directory: `cd /path/to/wordpress/wp-content/themes/`
3. Clone the repository: `git clone https://github.com/fmurdeni/mdporto-Block-Theme.git mdporto`
4. Navigate to the theme directory: `cd mdporto`
5. Install dependencies (if applicable): `npm install`
6. Activate the theme through the WordPress admin dashboard

## Requirements

- WordPress 6.0 or higher
- PHP 7.4 or higher
- Modern web browser

## Customization

MDPorto can be customized through:

1. **Site Editor**: Use WordPress's built-in site editor to modify templates and template parts
2. **Global Styles**: Customize colors, typography, and spacing through the global styles interface
3. **Theme.json**: Advanced users can modify the theme.json file for deeper customization
